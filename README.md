# Ycotek Bootcamp – Data Engineering

Welcome to my **Ycotek Bootcamp** repository!

This repository contains my learning activities, assignments, and hands-on projects completed during the Ycotek Bootcamp, with a focus on **Data Engineering**.

## About This Repository

Throughout the bootcamp, I work on building practical data engineering solutions and understanding how data moves from raw sources to structured, analytics-ready datasets.

The projects focus on:

- Building ETL and data pipelines.
- Extracting, transforming, and loading data.
- Designing data warehouse architectures.
- Working with structured and semi-structured data.
- Implementing data validation and quality checks.
- Automating workflows and pipeline execution.
- Managing historical data and ensuring data consistency.

## Technologies & Tools

The repository includes hands-on work with:

- **Python** – Data processing and pipeline development.
- **SQL** – Data querying, transformation, and validation.
- **Snowflake** – Cloud data warehousing.
- **Apache Airflow** – Workflow orchestration and pipeline automation.
- **Docker** – Containerization and local development environments.
- **Git & GitHub** – Version control and project management.
- **Pytest** – Automated testing.

## Data Engineering Concepts

Some of the concepts explored include:

- ETL pipeline development
- Bronze, Silver, and Gold architecture
- Data warehouse design
- Fact and dimension tables
- Star and Snowflake schemas
- Slowly Changing Dimensions (SCD Type 1 and Type 2)
- Data quality checks and quarantine handling
- Data reconciliation
- Pipeline automation and idempotency

## Repository Structure

Each assignment or project is organized into its own directory, containing relevant source code, SQL scripts, configuration files, documentation, tests, and supporting evidence where applicable.

## Learning Goal

My goal is to develop practical Data Engineering skills by building end-to-end pipelines, understanding modern data platforms, and applying industry-relevant engineering practices.
